## 课程总览

1. Lesson01 颜色渐变:像素方向 -> 颜色,建立"每像素一条光线"的直觉
2. Lesson02 立方体线框:4x4 矩阵变换 + 画线
3. Lesson03 光线追踪立方体:三角形求交 + 最近交点
4. Lesson04 球体:一元二次方程求交
5. Lesson05 光照与阴影:环境光/漫反射/阴影射线
6. Lesson06 多球 + 镜面高光:Blinn-Phong
7. Lesson07 平面棋盘格 + 反射:递归光线
8. Lesson08 轨道相机:LookAt + 透视
9. Lesson09 超采样抗锯齿:每像素多条子光线
10. Lesson10 多线程渲染(支线):按行拆任务,多线程加速
11. Lesson11 贴图与材质(支线):PPM 贴图 + 球面 UV,世界地图做成旋转地球
12. Lesson12 MC 玻璃块与 PNG 贴图(支线):PNG RGBA 贴图 + alpha 混合,玻璃方块展示
