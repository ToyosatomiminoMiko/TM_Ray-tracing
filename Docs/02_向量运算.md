# 向量运算

三维向量用三个浮点数表示:`Vector_3 { x, y, z }`.
实现位于 `Core/math/vec3.c`,全部是纯函数.

## 加减与数乘

逐分量计算:

```
a + b = (ax+bx, ay+by, az+bz)
a - b = (ax-bx, ay-by, az-bz)
s * v = (s*vx, s*vy, s*vz)
```

几何意义:加法是"先走 a 再走 b",减法是"从 b 指向 a 的向量".

## 点积(dot)

```
a·b = ax*bx + ay*by + az*bz
```

点积结果是一个标量,且 `a·b = |a|*|b|*cos(θ)`.
当两个向量都是单位向量时,点积直接就是夹角的余弦:

- `> 0`:夹角小于 90°,光从正面照过来;
- `= 0`:垂直,光线擦边;
- `< 0`:夹角大于 90°,光从背面照过来.

这就是漫反射里 `N·L` 的来历.

## 叉积(cross)

```
a×b = (ay*bz - az*by, az*bx - ax*bz, ax*by - ay*bx)
```

叉积结果垂直于 a 和 b 所在平面,方向满足右手定则.
用途:

- 由两个三角形边求法线;
- 由相机前方向与上方向构造右方向;
- 判断平面朝向.

## 长度与归一化

```
|v|   = sqrt(vx² + vy² + vz²)
v̂     = v / |v|
d(a,b) = |a - b|
```

归一化只保留方向/不改变方向.光线方向/法线/光照方向在使用前都要归一化,
否则 `N·L` 会受长度影响,亮度失真.

零向量归一化会除零,所以实现里加了阈值保护.

## 线性插值 lerp

```
lerp(a, b, t) = a + t*(b - a),  t ∈ [0,1]
```

t=0 得到 a,t=1 得到 b.反射课程里用来按反射率混合"局部颜色"和"反射颜色".

## 反射 reflect

```
r = d - 2*(d·n)*n
```

前提是法线 n 已经归一化.这是镜面反射的基础:
入射方向 d 以法线为轴翻转,得到出射方向 r.
