# 轨道相机与透视

## 相机三要素

一台相机由三个量决定:

```
eye    眼睛位置
center 注视点
up     世界"上"方向(通常 (0,1,0))
```

由此得到相机坐标系:

```
f = normalize(center - eye)   前
s = normalize(f × up)         右
u = s × f                     上
```

## 生成光线

每个像素在视空间的方向(与第 04 篇相同):

```
half_h = tan(fov/2)
half_w = half_h * aspect
view_dir = (ndc_x*half_w, -ndc_y*half_h, -1)
```

然后乘观察矩阵的转置(旋转矩阵的逆)转回世界空间:

```
world_dir = view^T * view_dir
```

光线起点是 eye,方向是 world_dir 归一化。

## 轨道动画

让 eye 绕 Y 轴转:

```
eye.x = R*cos(θ)
eye.z = R*sin(θ)
```

每帧 θ 增加一点,就得到环绕场景的动画。
用 `look_at_4x4` 可以自动算出相机矩阵,不用手写坐标系。

## 与投影矩阵的关系

传统 GPU 管线把场景变换到裁剪空间后做透视除法;光线追踪不做除法,
而是直接从像素位置生成"恰好穿过这个像素"的光线。两者视角数学相同,
只是采样方向相反:一个从相机向外发射光线,一个把顶点投进屏幕。
