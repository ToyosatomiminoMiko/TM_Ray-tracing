# 贴图与材质:世界地图 → 地球

## 从"画颜色"到"贴图"

前几课里,每个物体的颜色是一个固定的 RGB 值(albedo):

```c
vec3 albedo = {0.2f, 0.7f, 0.2f}; /* 每个像素都同一个绿色 */
```

Lesson11 把颜色换成一张图片:命中点先算出它在图片里的坐标 (u, v),
再去图片里取那个位置的颜色.这个过程叫**贴图(texture mapping)**.

这里有两个坐标系,必须分清楚:

- 几何坐标 (x, y, z):物体在三维空间里的位置;
- 纹理坐标 (u, v):图片里的位置,u 是横坐标(0 左 → 1 右),
  v 是纵坐标(0 上 → 1 下);
- 中间需要一个映射函数,把球面点换算成 (u, v).

## 等距圆柱投影(Equirectangular Projection)

素材 `world.ppm` 是 1275×638 的等距圆柱世界地图:
宽度正好是高度的两倍,因为经度跨 360°、纬度跨 180°,
经度方向要铺两倍的像素.

球面上一点 P,先换算成单位法线 n = (P − C) / R:

$$
\varphi = \arcsin(n_y) \qquad
\lambda = \operatorname{atan2}(n_x, n_z)
$$

其中 φ 是纬度、λ 是经度.相机在原点朝 -Z 看,可见半球的外法线朝 +Z;
取 `atan2(n.x, n.z)` 可以让本初子午线正对相机,东经在屏幕右侧、西经在左侧.

经纬度到 UV 的换算:

$$
u = 0.5 + \frac{\lambda}{2\pi} \qquad
v = 0.5 - \frac{\varphi}{\pi}
$$

含义:

- u 是"经度占整圈 360° 的比例",u = 0.5 对应本初子午线;
- v 是"纬度占 180° 的比例",v = 0 是北极(图片第一行),
  v = 1 是南极;
- 减号是因为图片的 v 向下增长,而地球纬度向北增长,两者方向相反.

这套映射就是常见的"等距圆柱贴图",全景图和世界地图都在用.

## 采样:最近邻 vs 双线性

UV 是连续的浮点数,图片是离散的像素网格,取色有两种做法:

1. **最近邻(nearest)**:直接取离 (u, v) 最近的像素.
   快,但放大后能看到方块锯齿;
2. **双线性(bilinear)**:取周围 2×2 像素,先水平插值、再垂直插值.
   画面平滑,是渲染器里最常用的做法.

两个方向的处理方式不同,这是等距圆柱地图的特殊之处:

- **u 方向循环包裹**:地图左右边缘分别是 −180° 和 +180°,
  本来就该接在一起,所以 `u = u - floor(u)`;
- **v 方向夹紧**:北极/南极是"点"而不是环,图片上下边缘不应拼接,
  所以 `v` 超过 [0,1] 时取最近的边缘行.

## 材质:贴图只是漫反射颜色

贴图只解决"每个点是什么颜色",至于这个颜色怎么被光照亮,
由**材质(material)**决定.Lesson11 的材质结构:

```c
typedef struct
{
    const Texture *diffuse_map; /* 漫反射贴图:颜色来源 */
    vec3 specular;              /* 高光颜色 */
    float shininess;            /* 反光度:越大高光越集中 */
    float ambient;              /* 环境光比例 */
    float atmosphere;           /* 大气边缘光强度 */
} Material;
```

着色时:

1. 用贴图采样结果当漫反射颜色;
2. 平行光漫反射:`亮度 = ambient + (1 - ambient) * max(N·L, 0)`;
3. Blinn-Phong 高光:`pow(max(N·H, 0), shininess)`;
4. 大气边缘光:视线越贴地表(N·V 越小),叠的蓝光越强,
   这是对大气散射的简化近似(菲涅尔形式).

同一个球体,换一组材质参数,观感就完全不同:
哑光塑料、光滑水面、金属球,区别全在 specular/shininess 上.

## 旋转动画:滚动 UV,不旋转几何体

地球自转看起来是"大陆在球面上移动".因为 u 本身就是经度,
让采样坐标随时间减小,等价于把整张贴图往东滚动:

```c
float u, v;
sphere_uv_at(earth, P, &u, &v);
u -= progress; /* progress = 当前帧 / 总帧数,一整个循环转一圈 */
```

这样几何体、法线、光照全部不用动,只需要改一个采样坐标,
就能得到自西向东的自转效果.
