# 超采样抗锯齿

## 锯齿从哪来

每个像素只发一条光线,打在物体边缘时"要么是物体、要么是背景",
于是出现生硬的阶梯状边缘(锯齿)。

## 思路:一个像素发多条光线

把像素想象成一个小方格,在里面均匀取 4x4 = 16 个点,
每个点发一条子光线,颜色取平均:

```
color = (c1 + c2 + ... + c16) / 16
```

边缘像素会得到"物体颜色和背景颜色的混合",看起来就是平滑过渡。

## 子像素位置

第 sx 行第 sy 列的子像素中心:

```
ox = (sx + 0.5) / 4
oy = (sy + 0.5) / 4
```

传给 `ray_direction_subpixel(i, j, W, H, fov, ox, oy)`。
这和第 04 篇的公式完全一致,只是像素中心偏移不同。

## 代价

4x4 超采样 = 16 倍光线数,渲染时间也约 16 倍。
这就是为什么游戏里常用 2x2,或者只在边缘像素做额外采样(需要先检测边缘)。
