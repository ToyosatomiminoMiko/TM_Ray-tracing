# 光线生成

## 从像素到方向

屏幕是 160x80 的像素网格,我们想知道"这个像素看到的是场景里的哪个方向".

第一步,把像素中心映射到 0..1:

```
u = (i + 0.5) / W
v = (j + 0.5) / H
```

加 0.5 是取像素中心,而不是左上角.

第二步,映射到 -1..+1,让屏幕中心成为坐标原点:

```
x = 2u - 1
y = 2v - 1
```

第三步,考虑宽高比与视场角.屏幕宽 160/高 80,横向能看到的范围更大:

```
half_h = tan(fov/2)
half_w = half_h * (W/H)
方向 = (x*half_w, -y*half_h, -1)
```

`fov = 90°` 时 `half_h = 1`,就是经典课程的写法.
最后把方向归一化,只保留方向.

## 光线的参数方程

一条光线由起点和方向决定:

```
P(t) = O + t*D,  t >= 0
```

t 是沿光线走的距离.求交就是在找满足条件的 t:

- 交点必须在光线前方:`t > 0`;
- 多个物体时取 `t` 最小的那个(最近的交点).

子像素采样(超采样)只是把 (i,j) 里的 0.5 换成像素内任意偏移 (ox,oy),
其余完全一样.
