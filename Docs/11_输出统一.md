# 统一输出到内存

## 旧方式的问题

旧代码有两种输出:

1. 终端动画:把 `Color_Buffer` 打印成 ANSI 彩色块;
2. 光照示例:渲染循环里直接 `fprintf` 写 `output.ppm`。

第二种方式把"场景计算"和"文件格式"耦合在一起:

- 场景逻辑里到处是 `FILE*`;
- 想同时看终端和存文件要写两遍;
- 想给动画存序列帧,得再复制一份代码。

## 新约定

所有课程只做一件事:往 `framebuffer_t` 里画像素。

```
framebuffer_t fb;
fb_clear(&fb);
lesson->render(&fb, frame);   // 画进内存
output_ansi(&fb);             // 或 output_ppm(&fb, path)
```

## 两种输出

### 终端 ANSI 动画

`output_ansi` 把每个像素输出为 ANSI 真彩色背景块:

```
\033[48;2;r;g;bm  \033[0m
```

每帧先 `output_clear_screen()` 清屏,再整幅打印。

### PPM 文件

PPM P3 是"纯文本 + RGB 数字"的极简格式:

```
P3
160 80
255
r g b
...
```

`output_ppm` 从帧缓冲读出每个像素并写入文件,课程代码里没有 `fopen`。

## 使用方式

```sh
./ray_tracing                 # 默认课程,终端动画
./ray_tracing lesson05        # 指定课程,终端显示
./ray_tracing lesson05 ppm    # 渲染到内存后写 out/lesson05.ppm
./ray_tracing list            # 列出课程
```

动画课程用 `ppm` 会按帧写出 `out/lessonXX_0000.ppm ...`,
之后可以用 ImageMagick 合成 GIF:

```sh
magick -delay 5 out/lesson08_*.ppm out/lesson08.gif
```
