# 三角形与平面求交

## Möller–Trumbore 三角形求交

三角形由三个顶点 V0/V1/V2 定义:

```
edge1 = V1 - V0
edge2 = V2 - V0
```

交点可以用重心坐标表示:

```
P = V0 + u*edge1 + v*edge2,  u>=0, v>=0, u+v<=1
```

把 `P = O + t*D` 代入,解三组未知数 (t, u, v).
用叉积构造中间向量:

```
h = D × edge2
a = edge1 · h
s = O - V0
q = s × edge1

u = (s · h) / a
v = (D · q) / a
t = (edge2 · q) / a
```

判断:

- `|a|` 接近 0:光线与三角形平行或共面;
- `u < 0 或 u > 1 或 v < 0 或 u+v > 1`:交点在三角形外;
- `t < 0`:交点在光线背后.

实现对应 `Core/raytrace/triangle.c` 的 `ray_triangle_intersect`.

## 平面求交

平面由法线 n 和平面上一点 P0 定义,平面方程:

```
n · (X - P0) = 0
```

代入光线:

```
n · (O + t*D - P0) = 0
t = ((P0 - O) · n) / (D · n)
```

当 `D·n` 接近 0 时,光线与平面平行,没有交点.
这个公式可以用来做无限大的地面,配合棋盘格纹理(按命中点坐标的奇偶性选颜色).

## 为什么三角形要拆成两个

四边形可以拆成两个三角形(0,1,2)和(0,2,3).
三角形是"凸的",重心坐标判断简单可靠,任何网格最后都会拆成三角形.
