# 球体求交

## 问题

球心 C/半径 R 的球面方程:

```
|X - C|² = R²
```

把光线 `X = O + t*D` 代入:

```
|t*D + (O-C)|² = R²
t²*(D·D) + 2t*(D·(O-C)) + (O-C)·(O-C) - R² = 0
```

这是关于 t 的一元二次方程:

```
a = D·D
b = 2*(D·(O-C))
c = (O-C)·(O-C) - R²
```

## 判别式与求根

```
Δ = b² - 4ac
```

- `Δ < 0`:没有实根,光线擦肩而过;
- `Δ = 0`:相切(只有一个交点);
- `Δ > 0`:两个交点,取 `t = (-b - sqrt(Δ)) / (2a)`,即最近的交点.

如果 `t < 0`,说明交点在相机背后,也算未命中.

## 优化版

方向 D 通常已经归一化,于是 `a = D·D = 1`,方程可以简化为:

```
b_half = D·(O-C)
Δ      = b_half² - c
t      = -b_half - sqrt(Δ)
```

少了一次乘法和开方前的运算,这就是 `intersect_sphere_fast`.

## 命中点与法线

命中点:

```
P = O + t*D
```

法线(球心指向命中点,再归一化):

```
N = (P - C) / R
```
